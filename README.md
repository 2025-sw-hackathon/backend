## 🤖 Project Overview

- 프로젝트 이름: 수워나이(SuwonAi)
- 프로젝트 목적: 수원대학교 홈페이지의 UI, 정보 접근, 사용자의 상호작용을 개선하기 위해 개발하였습니다.

## 🤖 Key Features

1. 학부학과, 졸업 요건 등 정보 제공
2. 캠퍼스 내 건물 간 이동 시간 계산
3. 학과별 클릭 배틀
4. AI 조교
